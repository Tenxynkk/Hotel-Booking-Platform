# Hotel Booking System - Frontend

## Project Overview
The frontend of the Hotel Booking System is developed using React.js and Vite.

## Technologies Used
- React.js
- Vite
- React Router
- Axios
- CSS

## Routing

React Router DOM is used for client-side navigation.

The application includes:
- Home
- Login
- Dashboard
- Profile
- Not Found (404)

## Installation

Install the required dependencies:

```bash
npm install
```

## Run the Application

```bash
npm run dev
```

Open the localhost address displayed in the terminal.

## Project Structure

- assets – Images, icons, fonts and stylesheets.
- components – Reusable UI components.
- layouts – Common page layouts.
- pages – Application pages.
- hooks – Custom React hooks.
- services – API-related services.
- utils – Helper functions.
- routes – Application routing.
