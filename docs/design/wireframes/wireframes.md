# Sprint 3 – Wireframes

These five low-fidelity page layouts show the structure and main interface elements of the Hotel Booking System:

1. **1-login.png** – Login form with email and password fields.
2. **2-dashboard.png** – Summary cards, recent bookings and quick actions.
3. **3-room-list.png** – Room search, room details, availability and management actions.
4. **4-add-edit-room.png** – Form for adding or updating room details.
5. **5-profile.png** – User profile details and save action.

The wireframes focus on layout and functionality rather than final colours or visual styling.
